# EmbyUnwatchedWash（未看洗版）

扫描 Emby / Jellyfin 中未观看（IsUnplayed）的影视，自动创建「洗版」订阅，让 MoviePilot 搜索更高画质版本替换旧版。

> Scan Emby/Jellyfin for unplayed movies & series and auto-create best-version subscriptions in MoviePilot.

## 功能特性

- **自动化洗版**：配合执行周期，新入库影视未观看即自动订阅洗版
- **手动选择**：在详情页未观看清单中勾选，只洗版指定的影视
- **剧集按集洗版**：按季订阅，「开始集数」指向第一个未观看的集，已看集不洗
- **已观看联动**：变为已观看后自动取消订阅 / 推进开始集数，避免白等
- **洗版规则组可配**：电影 / 剧集分别指定过滤规则组，留空用内置默认组
- **排除媒体库**：被排除的库整库跳过，不发起任何扫描请求
- **洗版后清理**：订阅完成后自动删除被洗版的低质量旧条目（只调 Emby 删除接口，不碰下载器与原始文件）
- **Dry-run 预览**：正式运行前先看待洗版清单，不真正创建订阅

## 安装

MoviePilot → 设置 → 插件 → 插件仓库 → 新增：

- 仓库地址：`https://github.com/jiuyaozhuce/MoviePilot-Plugins`
- 分支：`main`

保存后刷新仓库列表，安装「Emby未看洗版」即可。

## 配置说明

**基础设置**

- 启用插件：总开关

**执行计划**

- 执行周期：5 位 cron，留空每 30 分钟一次
- 单次最多处理数量：0 = 不限；大库建议先设 5~20 试跑，避免一次创建上千订阅

**运行模式**

- 运行模式：`自动化洗版`（对全部未排除库的未观看影视）/ `手动选择`（只处理清单勾选的条目）
- 自动化模式仍显示勾选清单：开启后详情页保留清单，可临时补充勾选
- 首次全量不设上限：洗版记录为空的首次运行忽略单次上限，整库一次铺完

**洗版范围**

- 包含剧集：关闭则仅洗版电影
- 剧集按未观看集洗版：默认开；关闭则整部剧洗版
- 电影 / 剧集洗版规则组：选项来自 MoviePilot「过滤规则」中自定义的规则组，留空用内置默认；组内条件含 FREE 即只下载免费资源

**已观看联动（订阅建好后追看）**

- 已观看即取消／收缩洗版订阅：电影已看 → 取消订阅；剧集已看 → 开始集数推进到第一个未看的集，整季看完 → 取消该季
- 观看状态核对服务器：留空核对全部已连接服务器；多服务器观看进度不一致时可只选其一

**排除规则**

- 排除媒体库：勾选的库整库跳过（不扫描、清单中不显示）
- 排除关键字：对库名做子串匹配（忽略大小写），命中即跳过

**洗版后清理**

- 洗版完成后删除旧版本：监听 MoviePilot「订阅完成」事件，延迟核对后删除该电影 / 该集的低质量旧条目——只调 Emby/Jellyfin 删除接口（软链接库结构下仅删软链），**不碰下载器种子与原始文件**；同一内容多版本时保留画质最高的一个。默认关闭
- 删除前延迟（分钟）：等待新版入库与媒体库刷新后再核对，避免误删。默认 10
- 安全规则：仅剩一个版本不动作；画质信息不全的条目永不删除；只删画质严格低于保留者；Dry-run 模式下只记录不真删；删除任务持久化，插件重启不丢

**试运行与手动触发**

- Dry-run 预览模式：只打印待洗版清单，不创建订阅
- 保存后立即运行一次：保存配置后立刻执行，执行完自动关闭

## 触发方式

- 定时：按「执行周期」运行（默认每 30 分钟）
- 手动：打开「保存后立即运行一次」并保存
- 远程命令：向 MoviePilot 发送 `/emby_wash`

## 排查：洗版不生效

1. 确认 MoviePilot 已开启「允许洗版 / 最佳版本」
2. 确认下载器与订阅站点可用（洗版需要站点上有更高画质资源）
3. 确认媒体服务器已接入且连接正常（自动化模式需要在线；手动选择模式可离线）
4. 确认 TMDB API Key 有效（媒体识别用）
5. 站点上当前没有更高画质版本时，订阅会一直等待，不会重复下载
6. 每条失败的具体原因都会写入插件日志

## 排查：旧版本删除失败

- 日志出现「删除条目失败（HTTP 401/403）」：到 Emby/Jellyfin 后台确认 API Key 所属用户拥有删除媒体权限
- 删除有延迟是正常的：订阅完成后需等待「删除前延迟」设定的分钟数再核对
- 日志出现「跳过删除（画质信息不全）」：新条目尚未被服务器识别完分辨率，属安全保护，可手动清理

## 说明

- 开启「洗版后清理」前本插件只创建 / 取消订阅，**不会删除任何媒体**；开启后也仅删除媒体服务器条目（软链接），不触碰下载器种子与原始文件
- 插件日志位于 `<数据目录>/config/logs/plugins/embyunwatchedwash.log`，搜索 `【未看洗版】` 即可过滤本插件输出
- Fork 自官方插件 `bestfilmversion`（收藏洗版），改为未观看语义；Plex 暂不支持
